The PDF exporter embeds Noto Sans Regular and Bold so reports include the naira
symbol and accented names without requesting a font from an external service.

Source: [Noto fonts](https://github.com/notofonts/noto-fonts/tree/main/hinted/ttf/NotoSans).
The font license is distributed in [OFL.txt](../../../public/fonts/OFL.txt).
